# Product Steering: NecroBOL (Kiroween 2026 - Resurrection)

NecroBOL resurrects legacy COBOL-85 batch programs inside an authentic IBM 3270 mainframe workbench running natively in the browser and exposed over the Model Context Protocol (MCP).

## Product Principles
1. **Zero Simulated Outputs:** Every execution step, Y2K date rollover, fixed-point `PIC` truncation warning, call-graph edge, and TypeScript/Python transpilation output must come from a real deterministic COBOL-85 engine (`src/engine/`).
2. **Explainable Exorcism:** Legacy bug detection must pinpoint exact source lines, assign an objective haunting score (`0` to `100`), highlight unreachable "ghost paragraphs" in the SVG control-flow graph, and explain concrete remediation steps.
3. **Byte-for-Byte Parity Proof:** Modernizing legacy COBOL requires proof that the replacement preserves legacy business behavior. Both the browser UI and MCP server compare COBOL stdout against transpiled TypeScript output line by line.
4. **Authentic 3270 Experience:** Preserve classic phosphor terminal ergonomics (PF3 Reset, PF5 Execute, PF8 Step, PF9 Exorcise & Modernize) with selectable phosphor green, amber gold, and spectral violet themes.
